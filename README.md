## 🇮🇷 فارسی
### 🚀 معرفی
**SAZ SPLITTER X** یک موتور حرفه‌ای و فوق‌پیشرفته برای استخراج، فیلتر و بهینه‌سازی کانفیگ‌های **V2Ray** از منابع مختلف است. این ابزار با طراحی سایبرپانک و رابط کاربری شبیه‌به‌ترمینال، به شما امکان می‌دهد:
- از **بیش از ۵۰ منبع معتبر** به‌صورت هم‌زمان کانفیگ دریافت کنید.
- کانفیگ‌های **VLESS**، **VMess**، **Trojan**، **Shadowsocks**، **Hysteria** و **Hysteria2** را استخراج کنید.
- بر اساس **پروتکل** و **ترانسپورت** دلخواه، فیلتر هوشمند اعمال کنید.
- کانفیگ‌ها را بر اساس **امتیاز کیفیت** (نوع پروتکل، امنیت، پورت، ترانسپورت) مرتب‌سازی کنید.
- خروجی نهایی را با **تگ دلخواه** شخصی‌سازی کرده و کپی یا دانلود کنید.
همه‌ی پردازش‌ها در مرورگر شما انجام می‌شود و **هیچ داده‌ای به سرور ارسال نمی‌شود**.

### 🧠 موتور پردازش (چطور کار می‌کند؟)
1. **دریافت داده**: ابزار ابتدا داده‌های ورودی را بررسی می‌کند. در صورت خالی بودن، از **۵۰+ منبع پیش‌فرض** استفاده می‌کند. در صورت وجود ورودی، لینک‌های HTTP/HTTPS را شناسایی و دریافت می‌کند و متن خام را نیز پردازش می‌کند.
2. **رمزگشایی**: داده‌های Base64 را شناسایی و رمزگشایی می‌کند تا کانفیگ‌های مدفون در آن‌ها را استخراج کند.
3. **استخراج URI**: با استفاده از رجکس‌های پیشرفته، تمام URIهای V2Ray (vmess://، vless://، trojan://، ss://، hysteria://، hysteria2://) را استخراج می‌کند.
4. **امتیازدهی**: هر کانفیگ را بر اساس پارامترهای زیر امتیازدهی می‌کند:
   - **پروتکل**: VLESS (۲۵+)، Hysteria2 (۲۰+)، Trojan (۱۵+)، VMess (۱۰+)
   - **امنیت**: Reality (۳۰+)، TLS/XTLS (۲۰+)
   - **ترانسپورت**: gRPC، XHTTP، SplitHTTP، WS (۱۵+)
   - **پورت**: ۴۴۳، ۸۴۴۳، ۲۰۵۳، ۲۰۸۳ (۱۵+)
5. **فیلتر**: کانفیگ‌هایی که پروتکل یا ترانسپورت آن‌ها انتخاب نشده باشد، حذف می‌شوند.
6. **حذف تکراری**: کانفیگ‌های تکراری بر اساس کلید یکتا (پروتکل+آدرس+پورت) حذف می‌شوند و بهترین نسخه (با بالاترین امتیاز) حفظ می‌شود.
7. **مرتب‌سازی و برش**: کانفیگ‌ها بر اساس امتیاز (نزولی) مرتب شده و تعداد مشخص‌شده (پیش‌فرض ۲۰۰۰) برش داده می‌شوند.
8. **اعمال تگ**: تگ دلخواه کاربر روی تمام کانفیگ‌ها اعمال می‌شود.
9. **خروجی**: نتایج نهایی برای کپی یا دانلود آماده می‌شوند.

## 🇬🇧 English
### 🚀 Introduction
**SAZ SPLITTER X** is a professional, state‑of‑the‑art engine for extracting, filtering, and optimising **V2Ray** configurations from multiple sources. Featuring a cyberpunk design and a terminal‑like interface, this tool allows you to:
- Fetch configurations from **over 50 trusted sources** simultaneously.
- Extract **VLESS**, **VMess**, **Trojan**, **Shadowsocks**, **Hysteria**, and **Hysteria2** configs.
- Apply smart filters based on **protocol** and **transport** types.
- Rank configs using a **quality scoring** system (protocol type, security, port, transport).
- Customise the final output with a **personalised remark tag**.
- Copy or download the final result with one click.
All processing happens locally in your browser – **no data is ever sent to any server**.

### 🧠 Processing Engine (How it Works)
1. **Data Ingestion**: The tool first checks the input data. If empty, it uses **over 50 default sources**. If input is provided, it identifies HTTP/HTTPS links and fetches them, while also processing raw text.
2. **Decoding**: Identifies and decodes Base64‑encoded data to extract hidden configs.
3. **URI Extraction**: Using advanced regex patterns, it extracts all V2Ray URIs (vmess://, vless://, trojan://, ss://, hysteria://, hysteria2://).
4. **Scoring**: Each config is scored based on:
   - **Protocol**: VLESS (+25), Hysteria2 (+20), Trojan (+15), VMess (+10)
   - **Security**: Reality (+30), TLS/XTLS (+20)
   - **Transport**: gRPC, XHTTP, SplitHTTP, WS (+15)
   - **Port**: 443, 8443, 2053, 2083 (+15)
5. **Filtering**: Configs whose protocol or transport is not selected are dropped.
6. **Deduplication**: Duplicate configs (based on protocol+address+port) are removed, keeping only the highest‑scoring version.
7. **Sorting & Truncation**: Configs are sorted by score (descending) and truncated to the specified limit (default 2000).
8. **Remark Application**: The user's custom remark tag is applied to all configs.
9. **Output**: Final results are ready for copy or download.

### 🖥️ How to Use (Step‑by‑Step)
1. Open `index.html` in your browser.
2. **Data Input**:
   - Paste subscription links (HTTP/HTTPS) into the text box.
   - Or paste raw text containing Base64 or URI configs.
   - Or click the **Attach** button to upload a text file (TXT, CONF, JSON).
   - If left empty, the system will use **over 50 default sources**.
3. **Custom Remark**: Enter a remark tag for the output configs (default: `SAZ🏴‍☠️`).
4. **Max Nodes**: Set the maximum number of configs to output (default 2000).
5. **Select Protocols**: Choose the desired protocols (VLESS, VMess, Trojan, SS, Hysteria, Hysteria2).
6. **Select Transports**: Choose the desired transports (WS, gRPC, TCP, TLS, HTTPUpgrade, SplitHTTP, XHTTP, H2, QUIC).
7. Click the **INITIALIZE SEQUENCE** button.
8. The operation will be displayed in the terminal with a progress bar.
9. Upon completion, the number of extracted configs will be shown under **NODES ACQUIRED**.
10. Use the **COPY SECURE DATA** and **DOWNLOAD .TXT** buttons to copy or download the output.
