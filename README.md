# 🇮🇷 فارسی

## 🚀 معرفی

**MATIN TECH - Quantum Nexus Elite** یک پلتفرم حرفه‌ای برای استخراج، مدیریت و بهینه‌سازی کانفیگ‌های **V2Ray** است که با رابط کاربری مدرن، موتور پردازش هوشمند و معماری کاملاً **Client-Side** طراحی شده است.

تمام پردازش‌ها مستقیماً داخل مرورگر انجام می‌شوند و هیچ اطلاعاتی به سرور ارسال نمی‌شود.

# ⚡ Quick Start

### اجرای پروژه

```bash
git clone https://github.com/matinejlali5-cell/Matin-Tech.git
```

یا فایل ZIP را دانلود کرده و فایل زیر را اجرا کنید.

```text
index.html
```

### شروع کار

1. وارد پنل شوید.
2. لینک Subscription، فایل TXT یا متن خام را وارد کنید.
3. در صورت خالی بودن ورودی، منابع پیش‌فرض بارگذاری می‌شوند.
4. روی **INITIALIZE PROCESSING ENGINE** کلیک کنید.
5. خروجی را Copy یا Download نمایید.

### GitHub Pages

1. Upload the project to a public repository.

3. Select **Deploy from Branch**.
4. Choose **main** branch and **/(root)**.
5. Save the changes.
